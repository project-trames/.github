# Trames community

Organization profile and shared community files for **Project Trames**.

This is the public community repository for [Project Trames](https://github.com/project-trames).
GitHub displays [`profile/README.md`](profile/README.md) on the organization's
Overview page. This root README explains the community repository itself.

| File | Purpose |
| :--- | :--- |
| [Organization profile](profile/README.md) | Public introduction and product directory. |
| [Contributing](CONTRIBUTING.md) | Shared contribution and validation expectations. |
| [Support](SUPPORT.md) | Where to ask questions and how to report problems. |
| [Security policy](SECURITY.md) | Private vulnerability reporting and investigation scope. |
| [Code of conduct](CODE_OF_CONDUCT.md) | Community expectations, private reports, and moderation. |
| [Issue forms](.github/ISSUE_TEMPLATE) | Bug reports and feature proposals. |
| [Pull request template](.github/PULL_REQUEST_TEMPLATE.md) | Change context and validation evidence. |

Repository-specific community files take precedence over organization defaults.
Product code, build instructions, architecture records, and release artifacts
stay in their owning repositories.
